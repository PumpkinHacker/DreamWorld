# Dream World — Version 29

## What's new in v29
- Added five playable Space Dimension levels: Moon Base, Asteroid Run, Planet Garden, Alien Arcade, and Cosmic Crown.
- Added a Space Dimension portal on the level screen.
- Added a completely separate Space Shop with 50+ space-themed skins and gear, plus selectable animal designs including Space Cat.
- Added space scenery, floating collectibles, and space-level progression.
- The original Star Shop, learning activities, levels, achievements, customization, parent tools, and mod tools are retained from Version 27.

## Publish
Upload the included `index.html` to the root of your GitHub Pages repository. Keep your existing admin/worker files and configuration unchanged.

Progress and unlocks remain local to each browser/device, as in the original game.
